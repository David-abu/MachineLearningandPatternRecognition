\section*{Question 1}

Generated $N=10{,}000$ samples ($L=1$ with probability 0.65): $N_0=3460$, $N_1=6540$. Seed 5644; data saved in \texttt{q1\_data.npz}.

\subsection*{Part A: ERM with the true pdf}

\textbf{1. Decision rule.} The conditional risk of decision $i$ is $R(D{=}i\mid\x)=\sum_j\lambda_{ij}P(L{=}j\mid\x)$. Deciding $D=1$ is optimal iff $R(D{=}1|\x)<R(D{=}0|\x)$:
\begin{gather*}
\lambda_{10}P(L{=}0|\x)+\lambda_{11}P(L{=}1|\x) < \lambda_{00}P(L{=}0|\x)+\lambda_{01}P(L{=}1|\x)\\
\iff (\lambda_{01}-\lambda_{11})\,p(\x|L{=}1)P(L{=}1) > (\lambda_{10}-\lambda_{00})\,p(\x|L{=}0)P(L{=}0),
\end{gather*}
using Bayes' rule and cancelling $p(\x)$. Assuming $\lambda_{01}>\lambda_{11}$ (an error costs more than a correct decision), the minimum-expected-risk rule is the likelihood-ratio test
\[
\boxed{\;\frac{p(\x\mid L=1)}{p(\x\mid L=0)} \;\underset{D=0}{\overset{D=1}{\gtrless}}\; \gamma=\frac{(\lambda_{10}-\lambda_{00})\,P(L=0)}{(\lambda_{01}-\lambda_{11})\,P(L=1)}\;}
\]
For minimum probability of error (0--1 loss: $\lambda_{00}=\lambda_{11}=0$, $\lambda_{01}=\lambda_{10}=1$): $\gamma^*=P(L{=}0)/P(L{=}1)=0.35/0.65=0.5385$, $\ln\gamma^*=-0.619$.
With Gaussian class conditionals the test is implemented in the log domain (numerically stable, monotone so equivalent):
\[
\ln\frac{p(\x|1)}{p(\x|0)} = -\tfrac12(\x-\m_1)^T C_1^{-1}(\x-\m_1)+\tfrac12(\x-\m_0)^T C_0^{-1}(\x-\m_0)-\tfrac12\ln\frac{|C_1|}{|C_0|}\;\gtrless\;\ln\gamma .
\]
This is a quadratic discriminant, since $C_0\neq C_1$.

\textbf{2. ROC.} The score $s(\x_n)=\ln[p(\x_n|1)/p(\x_n|0)]$ was computed for all samples. Sweeping $\ln\gamma$ from $-\infty$ through every observed score value (10{,}001 thresholds) gives every distinct operating point the data can produce; for each, $P(D{=}1|L{=}1;\gamma)$ and $P(D{=}1|L{=}0;\gamma)$ are estimated by counts. At $\gamma=0$ the curve is at $(1,1)$; at $\ln\gamma=\max_n s(\x_n)$ (finite) it reaches $(0,0)$. Both $P(D{=}1|L{=}0;\gamma)$ and $P(D{=}0|L{=}1;\gamma)=1-P(D{=}1|L{=}1;\gamma)$ are stored for each threshold.

\textbf{3. Minimum-$P(\text{error})$ threshold.} For each threshold,
\[P(\text{error};\gamma)=P(D{=}1|L{=}0;\gamma)P(L{=}0)+P(D{=}0|L{=}1;\gamma)P(L{=}1);\]
the minimizer is marked on the ROC (Fig.~\ref{fig:q1a}). Any $\gamma$ between two consecutive sorted scores gives the same decisions; I report the midpoint. Results are in Table~\ref{tab:q1}.

\subsection*{Part B: Naive Bayes (diagonal covariance) model mismatch}
The classifier uses the same LRT and threshold formula but with $C_0^{NB}=\operatorname{diag}(C_0)=\operatorname{diag}(0.5,0.25,0.25,0.5)$ and $C_1^{NB}=\operatorname{diag}(C_1)=\operatorname{diag}(1,2,1,3)$, i.e.\ it ignores the correlations among $x_1,x_2,x_3$ ($x_4$ is already uncorrelated). The score is $\ln g(\x|\m_1,C_1^{NB})-\ln g(\x|\m_0,C_0^{NB})$ and the same sweep is performed on the same 10K samples (Fig.~\ref{fig:q1a} right, Table~\ref{tab:q1}).

\begin{itemize}
\item Minimum $\hat P(\text{error}) = \mathbf{0.0325}$ at $\hat\gamma\approx0.640$ (vs.\ $0.0326$ at $\gamma^*=0.538$). Monte Carlo with 2M samples at $\gamma^*$: $0.0322$.
\item The ROC moves down/right (AUC $0.9958\to0.9941$) and the best achievable error rises by about 25\% relative ($0.0259\to0.0325$; $0.0262\to0.0322$ with 2M samples).
\item Here $\gamma^*$ from priors and losses is no longer guaranteed optimal, because the NB ratio is not the true likelihood ratio, so thresholding it at $\gamma^*$ is not the Bayes rule. Empirically the best threshold ($0.64$) is still close to $\gamma^*$ and the error at $\gamma^*$ is almost the same as the minimum.
\end{itemize}
\textbf{Conclusion:} yes, the mismatch hurts, but moderately. The decision boundary is still quadratic and uses the correct means and variances; it only has the wrong orientation of the quadrics in the $(x_1,x_2,x_3)$ subspace. The correlations ($|\rho|\le 0.5$) are moderate and the class means are well separated (distance 3), so the loss is noticeable but not dramatic.

\subsection*{Part C: Fisher LDA}
Sample-average estimates from the 10K samples:
\[\hat{\m}_0=(-0.500,-0.505,-0.496,-0.498)^T,\quad \hat{\m}_1=(1.011,1.016,0.995,0.983)^T,\]
and
\[\hat C_j=\tfrac1{N_j}\textstyle\sum_{n:L_n=j}(\x_n-\hat\m_j)(\x_n-\hat\m_j)^T\]
(both close to the true $C_0,C_1$).
With equal weights, $S_B=(\hat\m_1-\hat\m_0)(\hat\m_1-\hat\m_0)^T$ and $S_W=\hat C_0+\hat C_1$. The Fisher criterion $J(\w)=\frac{\w^TS_B\w}{\w^TS_W\w}$ is maximized by the generalized eigenvector $S_B\w=\lambda S_W\w$ with the largest eigenvalue ($\lambda_{\max}=4.689$; $S_B$ has rank 1 so this is the only nonzero one). Normalized and oriented so that class 1 projects higher,
\[
\w_{LDA}=(0.6028,\;0.2747,\;0.7086,\;0.2432)^T,
\]
which equals the closed form $S_W^{-1}(\hat\m_1-\hat\m_0)/\|\cdot\|$ (checked numerically). The rule is $D=1$ iff $\w_{LDA}^T\x>\tau$; sweeping $\tau$ over $(-\infty,\infty)$ (all projected values) gives the ROC in Fig.~\ref{fig:q1c}. The error at each $\tau$ is estimated by sample counts, $\#\{\text{errors}\}/N$.

Minimum $\hat P(\text{error})=\mathbf{0.0521}$ at $\hat\tau\approx-0.0053$ ($P(D{=}1|L{=}1)=0.951$, $P(D{=}1|L{=}0)=0.058$), AUC $=0.9853$.

\begin{figure}[H]\centering
\includegraphics[width=0.49\linewidth]{figs/q1c_roc.png}\hfill
\includegraphics[width=0.49\linewidth]{figs/q1_compare.png}
\caption{Left: Fisher LDA ROC with the minimum-$P(\text{error})$ point. Right: zoomed comparison of the three ROC curves.}\label{fig:q1c}
\end{figure}

\textbf{Discussion.} The ranking is true-pdf ERM ($0.0259$) $<$ naive Bayes ($0.0325$) $<$ LDA ($0.0521$), and the ROC curves are nested the same way (Fig.~\ref{fig:q1c} right). LDA roughly doubles the error of the optimal classifier. The reason is structural: the Bayes rule is quadratic because $C_1$ has much larger variances than $C_0$ (e.g.\ $\operatorname{var}(x_4)$ is 3 vs.\ 0.5), so the optimal boundary is a closed-ish surface wrapped around the tight class-0 cloud. LDA can only use a hyperplane, and Fisher's criterion (one pooled within-class scatter, equal weights) is only optimal for equal-covariance Gaussians. Naive Bayes, although its covariances are wrong, still exploits the covariance difference through a quadratic boundary, which is why it beats LDA here. LDA also ignores the priors in finding $\w$, but this does not matter for the result since the threshold $\tau$ is selected empirically. LDA's advantages are that it needs no distributional knowledge and only $d$ projection parameters.

\subsection*{Part B: ERM with $\Lambda_{10}$ and $\Lambda_{100}$}
The ERM rule is $D(\x)=\arg\min_i\sum_j\lambda_{ij}P(L{=}j|\x)$. For $\Lambda_w=\begin{bmatrix}0&1&w\\1&0&w\\1&1&0\end{bmatrix}$ (with $P_j\equiv P(L{=}j|\x)$):
\[
R(1|\x)=P_2+wP_3,\quad R(2|\x)=P_1+wP_3,\quad R(3|\x)=P_1+P_2=1-P_3 .
\]
Between 1 and 2 the $wP_3$ term cancels, so that choice is still by larger posterior. Class 3 is chosen iff $1-P_3<\min(P_1,P_2)+wP_3$, i.e.
\[
P(L{=}3|\x) > \frac{1-\min\{P(L{=}1|\x),P(L{=}2|\x)\}}{w+1}.
\]
The right side lies between $\tfrac{1}{2(w+1)}$ and $\tfrac1{w+1}$. So with $w=10$, class 3 is chosen once its posterior exceeds at most $1/11\approx0.09$; with $w=100$, once it exceeds at most $1/101\approx0.01$.

The minimum expected risk is estimated by the sample average of the loss actually incurred, $\hat R_{\min}=\frac1N\sum_n\lambda_{D(\x_n),L_n}$. A second, lower-variance estimate is $\frac1N\sum_n\min_iR(D{=}i|\x_n)$, which uses the true posteriors. Both agree closely:

\textbf{Insights.}
\begin{itemize}
\item \emph{Risk vs.\ error.} As $w$ grows, ERM trades many cheap errors for few expensive ones. Class-3 recall goes $0.850\to0.983\to0.999$, while recall of classes 1 and 2 collapses ($0.796\to0.491\to0.180$ and $0.820\to0.604\to0.345$). The number of $D=3$ decisions rises from 4210 to 6500 to 8387. $P(\text{error})$ rises sharply ($0.175\to0.276\to0.439$), but this is the risk-optimal behaviour, not a failure.
\item \emph{Minimum risk grows with $w$} ($0.175\to0.339\to0.488$): larger penalties cannot reduce the best achievable risk. However, the growth is strongly sub-linear in $w$ because the classifier adapts. Under $\Lambda_{100}$ only 5 of 4057 class-3 samples are missed, yet those 5 still contribute $500/10^4=0.05$ to the risk. The remaining $\approx0.44$ comes from the 4335 class-1/2 samples labelled 3 at cost 1 each.
\item \emph{Asymmetry between classes 1 and 2:} class 1 loses more recall than class 2. Because of the covariance orientations, more of class 1's probability mass lies where $P(L{=}3|\x)$ exceeds the low class-3 threshold.
\item In the limit $w\to\infty$ the rule degenerates to ``always decide 3'', with risk $0.6$ (all class-1/2 samples wrong at cost 1). The sweep shows the risk approaching that value (0.571 at $w=500$).
\end{itemize}

\section*{Question 3}

\subsection*{Model, estimators and decision rule}
For each dataset with classes $j\in\mathcal{C}$ and samples $\{(\x_n,L_n)\}_{n=1}^N$, $\x_n\in\mathbb{R}^d$:
\begin{enumerate}
\item \textbf{Assumptions.} Samples are i.i.d.; the class-conditional pdf of each class is a single multivariate Gaussian, $p(\x|L{=}j)=g(\x|\m_j,C_j)$, with its own full covariance (heteroscedastic, i.e.\ a quadratic-discriminant model). No independence between features is assumed.
\item \textbf{Preprocessing.} Each feature is z-scored with the global mean and standard deviation, $\tilde x_k=(x_k-\bar x_k)/s_k$. An invertible affine map changes every $\ln p(\x|j)$ by the same constant (the log-Jacobian) and leaves an \emph{unregularized} Gaussian classifier's decisions unchanged. Regularization with $\lambda I$ is \emph{not} affine-invariant, though, and wine features differ in variance by $\sim10^8$ (e.g.\ total SO$_2$ vs.\ density). Standardizing makes $\lambda I$ an isotropic shrinkage in comparable units. Without it, the same classifier on raw wine features has training error $0.600$ instead of $0.503$, because $\lambda$ swamps the small-variance features.
\item \textbf{Estimates (maximum likelihood / sample averages).} $\hat P(L{=}j)=N_j/N$; $\hat\m_j=\frac1{N_j}\sum_{n:L_n=j}\x_n$; $\hat C_j=\frac1{N_j}\sum_{n:L_n=j}(\x_n-\hat\m_j)(\x_n-\hat\m_j)^T$.
\item \textbf{Regularization} (per class, following the hint): $C_j^{reg}=\hat C_j+\lambda_jI$ with $\lambda_j=\alpha\,\tr(\hat C_j)/\operatorname{rank}(\hat C_j)$, the arithmetic mean of the nonzero eigenvalues scaled by $\alpha$. All eigenvalues of $C_j^{reg}$ are then $\ge\lambda_j>0$.
\item \textbf{Decision rule} (0--1 loss, MAP): $D(\x)=\arg\max_j\big[-\tfrac12(\x-\hat\m_j)^T(C_j^{reg})^{-1}(\x-\hat\m_j)-\tfrac12\ln|C_j^{reg}|+\ln\hat P(L{=}j)\big]$, evaluated with Cholesky factors.
\item \textbf{Choosing $\alpha$.} Training error on all samples is not a valid criterion: it decreases as $\alpha\to0$ because the model memorizes. I therefore selected $\alpha$ on held-out data and then, as the assignment requires, re-estimated all parameters on all samples and report the all-sample (training) error and confusion matrix. Wine: stratified 5-fold cross-validation, giving $\alpha=10^{-3}$ (CV error is flat, about 0.515, for all $\alpha\le10^{-2}$). HAR: the dataset's own subject-disjoint train/test split, giving $\alpha=10^{-4}$. The sweep is in Table~\ref{tab:sweep} and Fig.~\ref{fig:sweep}.
\end{enumerate}

\subsection*{Discussion: are Gaussian class conditionals appropriate?}

\textbf{Wine --- poorly, and the problem itself is hard.}
\begin{itemize}
\item \emph{Non-Gaussian features.} Several marginals are strongly right-skewed or heavy-tailed (residual sugar, chlorides, free SO$_2$, volatile acidity; Fig.~\ref{fig:winehist}). The Q-Q plot (Fig.~\ref{fig:qq}, left) follows $\chi^2_{11}$ up to roughly the 80th percentile, then shows much heavier tails: outliers sit at Mahalanobis distances a Gaussian would essentially never produce. A log transform of the skewed features or a mixture/robust model would match better.
\item \emph{Overlap.} In every projection (Fig.~\ref{fig:winevis}) the quality classes overlap almost completely and differ mostly by small mean shifts along alcohol/density. The labels are subjective, ordinal taster scores, so even the true Bayes error is likely high. The confusion matrix shows this: nearly all errors are to adjacent grades (within $\pm1$: 92.7\%), and the Gaussian model's $P(\text{error})\approx0.50$ is only modestly better than the majority-class baseline (0.55).
\item \emph{How the model shaped the confusion matrix.} With near-identical means, the quadratic rule is driven largely by covariance differences and priors. Class 6 is the largest class (prior 0.45) but has only 40.5\% recall; 22\% and 35\% of its samples are assigned to the neighbouring grades 5 and 7, whose Gaussians overlap it almost completely. Rare grades are handled very differently. Class 9 (5 samples) gets a tiny, regularized Gaussian that recognizes its own 5 training points (5/5 correct), which is pure memorization. Class 3 (20 samples) gets 45\% recall on training data. With 77 parameters per class ($11+66$), these rare-class estimates have very high variance, and their training-set performance is not trustworthy. CV error (0.515) slightly above the training error (0.503) confirms mild overfitting overall.
\end{itemize}

\textbf{HAR --- not Gaussian, but the classes are so well separated that a Gaussian quadratic classifier still works very well.}
\begin{itemize}
\item \emph{Non-Gaussianity.} The features are bounded in $[-1,1]$ by construction and come from many subjects, so each class is a mixture of per-subject clusters. The Q-Q plot (Fig.~\ref{fig:qq}, right) is far from $\chi^2_{561}$: distances are too small for most samples (the data effectively live in a $\approx468$-dimensional subspace, and $\lambda$ inflates the null directions) and far too large in the tail. Strictly, the Gaussian model is wrong.
\item \emph{Separation.} PCA (Fig.~\ref{fig:harvis}) shows two groups split cleanly along PC1: dynamic activities (walking, upstairs, downstairs) and static ones (sitting, standing, laying). Laying is also distinct. The only confusions are within the static group (sitting$\leftrightarrow$standing: 18 samples) and within the dynamic group (12 downstairs and 1 walking sample decided as upstairs), exactly the physically similar pairs. In 561 dimensions, a quadratic boundary with class-specific covariances is flexible enough to separate these classes even though each class is not Gaussian.
\item \emph{Overfitting and the role of $\lambda$.} Each class model has $561+561\cdot562/2\approx158{,}000$ parameters estimated from $\sim1{,}700$ samples. The all-sample error of 0.30\% is therefore heavily optimistic: on unseen subjects the error is 8.2\%. Table~\ref{tab:sweep} shows the bias--variance trade-off. Large $\alpha$ (strong shrinkage toward a spherical covariance) underfits (error grows to 26--33\% at $\alpha=0.3$); tiny $\alpha$ leaves the near-null eigen-directions, which are dominated by numerical noise, nearly unpenalized. Training error is then not even monotone in $\alpha$, and held-out error is best at intermediate $\alpha=10^{-4}$ to $10^{-5}$.
\end{itemize}

\textbf{Summary.} The minimum-$P(\text{error})$ rule is only optimal if the assumed pdfs are correct. For wine, model mismatch (skewed, heavy-tailed, almost fully overlapping classes) plus severe class imbalance yields $\approx50\%$ error concentrated between adjacent grades. For HAR, the Gaussian model is also mismatched, but the class-conditional densities are concentrated in different regions, so the induced quadratic boundaries still achieve near-zero training error and $\approx8\%$ held-out error. In both cases regularization was essential: it made singular covariance estimates invertible (wine class 9; all HAR classes), and its strength set the bias--variance balance.
